# 09 — 成员头像 + 视觉打磨

**What to build:** 成员可以上传头像图片到 OSS，头像显示在评论区每条评论旁和 navbar 登录状态处。未上传头像的成员使用默认奶牛猫 avatar。奶牛猫吉祥物作为品牌贯穿全站：navbar logo、404 页面（迷路的奶牛猫）、内容加载占位动画、页脚。首页顶部全屏奶牛猫 hero 封面（占位图）+ 叠加站名"百草"和简介。全站移动端响应式适配。

**Blocked by:** #03 — 发布动态 + 图片上传 + 首页 Feed, #07 — 评论

**Status:** ready-for-agent

- [ ] 用户头像上传：个人设置页面或 navbar 下拉菜单中上传头像到 OSS，更新 User.avatar 字段
- [ ] 评论列表每条评论左侧显示评论者头像（无头像则显示默认奶牛猫 avatar）
- [ ] Navbar 登录状态处显示用户头像小图
- [ ] 默认 avatar：黑白奶牛猫简笔图标（SVG 占位）
- [ ] 404 页面：奶牛猫插画 + "这只猫迷路了" + 返回首页按钮
- [ ] 首页 hero section：全屏奶牛猫背景（占位图）+ 站名"百草" + 简介文字叠加
- [ ] 页脚：奶牛猫小图标 + 版权信息
- [ ] 内容加载中状态使用奶牛猫骨架屏/占位动画
- [ ] 全站响应式：移动端 navbar 折叠菜单、九宫格适配小屏、feed 单列全宽
