# 04 — 视频动态 + 长文模式

**What to build:** 管理员发布动态时可以选择上传 1 个视频（替代图片，两者互斥）。视频在 feed 卡片和详情页中内嵌播放器展示。同时，发帖界面增加"长文模式"开关：开启后出现标题输入框，可以写更长的纯文本正文。长文动态在 feed 中截断显示并标注"长文"，点击进入详情页查看完整标题和正文。

**Blocked by:** #03 — 发布动态 + 图片上传 + 首页 Feed

**Status:** ready-for-agent

- [ ] 发帖页面增加媒体类型切换：图片模式（最多 9 张）或 视频模式（最多 1 个），UI 上互斥
- [ ] `/api/posts` POST 增加校验：不允许同时提交 image 和 video 类型的 media
- [ ] 视频上传到 OSS，presigned URL 支持视频 MIME 类型
- [ ] Feed 卡片和详情页：视频用 `<video>` 标签内嵌播放
- [ ] 发帖页面增加"长文模式"开关（toggle），开启后显示标题输入框
- [ ] Post 创建 API 支持可选 title 字段和 isLongPost 标记
